# 🚀 QUICK START: Get Your PySpark Guide Online in 5 Minutes

**Option 1: GitHub Pages (Fastest - 3 minutes)**

```bash
# Step 1: Create folder
mkdir pyspark-guide
cd pyspark-guide

# Step 2: Copy your index.html here

# Step 3: Initialize git
git init
git add index.html
git commit -m "Add PySpark guide"

# Step 4: Create repo on GitHub
# Go to github.com/new
# Create repo named "pyspark-guide"

# Step 5: Push code
git remote add origin https://github.com/YOUR_USERNAME/pyspark-guide.git
git branch -M main
git push -u origin main

# Step 6: Enable Pages
# Go to repo → Settings → Pages
# Select "Deploy from a branch" → main branch → Save

# DONE! ✅ Your site is live at:
# https://YOUR_USERNAME.github.io/pyspark-guide
```

---

**Option 2: Netlify (Best Features - 5 minutes)**

```bash
# Step 1-5: Same as GitHub Pages above

# Step 6: Go to Netlify.com
# Click "Sign up with GitHub"
# Click "New site from Git"
# Select your pyspark-guide repo
# Click "Deploy site"

# DONE! ✅ Your site is live at:
# https://random-name.netlify.app
# (You can change this to custom domain)
```

---

**Option 3: Vercel (Modern - 5 minutes)**

```bash
# Step 1-5: Same as GitHub Pages above

# Step 6: Go to Vercel.com
# Click "Sign up with GitHub"
# Click "Add New..." → "Project"
# Select your pyspark-guide repo
# Click "Import" → "Deploy"

# DONE! ✅ Your site is live at:
# https://pyspark-guide.vercel.app
```
