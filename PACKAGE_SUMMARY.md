## Customization Guide

### Want to Change Colors?

**In index.html, find:**
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
/* #667eea = purple, #764ba2 = darker purple */
```

**Change to your favorite colors:**
```css
/* Blue theme */
background: linear-gradient(135deg, #3b82f6 0%, #1e40af 100%);

/* Green theme */
background: linear-gradient(135deg, #10b981 0%, #059669 100%);

/* Orange theme */
background: linear-gradient(135deg, #f97316 0%, #ea580c 100%);
```

### Want to Add Your Name?

**Find this line:**
```html
<header>
    <h1>🚀 PySpark Architecture & Execution Guide</h1>
    <p>A Comprehensive Learning Resource for Data Engineers</p>
</header>
```

**Change to:**
```html
<header>
    <h1>🚀 PySpark Architecture & Execution Guide</h1>
    <p>By Ajeet Singh | A Comprehensive Learning Resource</p>
</header>
```

### Want to Add Your Photo?

**In footer, add:**
```html
<footer>
    <img src="your-photo.jpg" alt="Your Name" style="width:100px; border-radius:50%;">
    <p>Created by You</p>
</footer>
```
